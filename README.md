# SupplyChain IQ - AI Logistics & Inventory Management Assistant

A web application designed for Logistics & Supply Chain inventory analysis using **React**, **Tailwind CSS**, and **Google Gemini AI**.

## 🎨 Design & Palette
- **Primary Accent:** `#FFBE0B` (Bright Yellow/Gold)
- **Background Dark:** `#2A2312` (Dark Charcoal/Brown)
- **Text:** White (`#FFFFFF`) & Cream (`#EAE2D6`)

## ⚡ Features
1. **API Key Management:** Input Gemini API key directly in the UI (saved in `localStorage`).
2. **Demo Mode:** If no API key is provided, the app runs smoothly using built-in evaluation logic.
3. **Threshold Analysis:** Compares item counts against a custom minimum threshold (default: 10).
4. **Structured JSON & Formatted Reports:** View status in clean tables or valid JSON format.
5. **Pre-built Test Cases:** 1-click execution for standard, edge case, and out-of-scope prompts.

## 🚀 How to Run
Simply double-click `index.html` or open it in any web browser!
